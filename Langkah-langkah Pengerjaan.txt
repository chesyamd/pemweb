Langkah-langkah pengerjaan

1. Menyiapkan struktur project
Membuat folder tugas2 untuk menyimpan seluruh file website, yaitu index.html, berita.html, detail_mahasiswa.html, tambah_data.html, dan logo.

2. Membuat halaman utama
Membuat index.html sebagai halaman dashboard yang terdiri dari header, logo, navigation menu, konten utama, informasi tambahan, dan footer.

3. Menerapkan struktur HTML semantik
Menggunakan elemen header, nav, main, section, article, aside, dan footer untuk menyusun bagian-bagian halaman sesuai fungsinya.

4. Membuat halaman berita
Membuat berita.html untuk menampilkan berita terkait ITERA. Isi berita disusun menggunakan elemen article dan informasi tambahan menggunakan aside.

5. Membuat halaman detail mahasiswa
Membuat detail_mahasiswa.html untuk menampilkan informasi mahasiswa dan data akademik menggunakan tabel. Data yang digunakan berupa data dummy.

6. Membuat halaman tambah data
Membuat tambah_data.html yang berisi form untuk memasukkan data mahasiswa menggunakan elemen form, label, input, dan button.

7. Menghubungkan antarhalaman
Menambahkan hyperlink pada navigation menu dan bagian tertentu agar setiap halaman dapat saling diakses.

8. Melakukan validasi dan pengujian
Memvalidasi seluruh file HTML menggunakan W3C Validator serta menguji link, tabel, form, dan gambar melalui browser.

9. Melakukan hosting
Mengunggah project ke repository GitHub pemweb pada folder tugas2, kemudian mengaktifkan GitHub Pages agar website dapat diakses secara online.
